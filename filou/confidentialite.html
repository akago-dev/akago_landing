Application Filou

Politique de confidentialité

Filou est une application de routine visuelle pour les enfants de 3 à 8 ans, éditée par Akago. Elle ne collecte aucune donnée : tout ce que vous y saisissez reste sur votre appareil.

Aucune donnée collectée

Filou ne demande pas de compte, ne vous identifie pas et ne transmet aucune information à Akago ni à un tiers. L'application ne contient ni publicité, ni outil de mesure d'audience, ni kit de développement tiers, et n'effectue aucune requête réseau : elle fonctionne intégralement hors ligne.

Ce qui est enregistré sur votre appareil

Pour fonctionner, Filou conserve localement, dans l'espace privé de l'application :

Vos journées types : les moments de la journée, leurs horaires, leurs pictogrammes et les petites tâches associées.

Vos réglages : pictogrammes choisis, affichage de l'heure, animations réduites, journée type du jour.

Le code parent : jamais enregistré en clair. Seule une empreinte cryptographique (SHA-256) est conservée, ce qui permet de vérifier le code sans pouvoir le retrouver.

Les cases cochées du jour et un journal d'usage technique (par exemple « une tâche a été cochée »), utilisés uniquement par l'application pour son propre fonctionnement. Ces informations ne quittent jamais l'appareil.

Aucune de ces données ne permet d'identifier une personne : Filou ne demande ni nom, ni date de naissance, ni adresse électronique, ni photo.

Enfants

Filou est conçue pour être utilisée par de jeunes enfants. C'est précisément pourquoi elle ne collecte rien : il n'y a aucune donnée d'enfant à transmettre, à stocker sur un serveur ou à partager. L'espace destiné aux parents est protégé par un appui long de trois secondes suivi d'un code à quatre chiffres, afin qu'un enfant ne modifie pas les réglages par inadvertance.

Sauvegardes de votre appareil

Si vous avez activé la sauvegarde de votre appareil (iCloud ou sauvegarde locale via un ordinateur), les données de Filou peuvent y être incluses, comme celles de vos autres applications. Cette sauvegarde est gérée par Apple selon ses propres conditions ; Akago n'y a pas accès.

Suppression des données

Désinstaller Filou supprime l'intégralité des données de l'application sur l'appareil. Comme rien n'est transmis à Akago, aucune demande de suppression n'a à être adressée : il n'existe aucune copie de votre côté serveur.

Vos droits

Le règlement général sur la protection des données (RGPD) vous ouvre des droits d'accès, de rectification et d'effacement sur vos données personnelles. Akago ne détenant aucune donnée issue de Filou, ces droits s'exercent directement depuis votre appareil. Pour toute question, vous pouvez écrire à contact@akago.fr.
