Application Filou

Assistance

Filou est une application de routine visuelle pour les enfants de 3 à 8 ans. Un petit ver avance sur le chemin de la journée : l'espace entre deux moments, c'est leur durée. Voici les questions qui reviennent le plus souvent.

Ouvrir l'espace parents

Touchez le bouton ⚙ en haut à gauche de l'écran, puis saisissez votre code à 4 chiffres.

Au tout premier lancement, l'application vous demande de choisir ce code, puis de le confirmer. Il protège les réglages pour qu'un enfant ne les modifie pas par mégarde.

J'ai oublié mon code

Il n'existe pas de récupération : le code n'est pas enregistré en clair, seule une empreinte cryptographique l'est, et rien n'est transmis à un serveur. Personne, pas même nous, ne peut le retrouver.

La seule issue est de désinstaller puis réinstaller l'application — ce qui efface aussi vos journées types et vos réglages, à reconfigurer entièrement. Une récupération est à l'étude pour une prochaine version.

Changer les horaires d'une journée

Dans l'espace parents, ouvrez une journée type — École, Mercredi, Week-end ou Vacances — et touchez un moment pour l'ajuster. Ce sont ces journées types que l'on modifie, pas les jours un par un.

Avant de valider, Filou annonce toujours l'effet du changement : « Les dents et toute la suite se décaleront de 10 min ». Rien ne bouge tant que vous n'avez pas enregistré.

Pour qu'une journée s'applique à un autre jour de la semaine, touchez les pastilles des jours sur sa carte dans le planning. Et pour changer la journée d'aujourd'hui seulement, utilisez « Jour type aujourd'hui » dans les réglages.

L'écran devient sombre le soir

C'est voulu. Passé l'heure du dodo, le chemin laisse place à une veilleuse : un écran apaisé qui indique l'heure du prochain réveil. Le bouton ⚙ reste au même endroit.

Changer d'appareil, sauvegarder

Dans cette première version, la configuration ne se synchronise pas entre appareils : chaque tablette ou téléphone garde la sienne. C'est la limite dont nous avons le plus conscience, et la synchronisation entre appareils et entre parents est notre prochain chantier.

En attendant, si la sauvegarde de votre appareil est activée (iCloud ou sauvegarde locale), les données de Filou y sont incluses comme celles de vos autres applications, et se restaurent avec elles.

Supprimer mes données

Désinstaller l'application supprime tout ce qu'elle contient sur l'appareil. Comme rien n'est transmis, il n'y a aucune copie ailleurs à faire effacer. Voir la politique de confidentialité.
